# 懂你一点 / A Little Closer

送礼指南与关系体验测评网页应用（纯前端部署版）。纸白、莓红与杂志式中文衬线排版，适配手机和桌面。

公共访问地址：https://zurcherism.github.io/a-little-closer/

## 本版本说明

本站由原 Codex 全栈版本（SQLite / Cloudflare D1 后端）改造为**纯静态站点**，可直接托管于 GitHub Pages：

- `local-api.js` 在浏览器内拦截 `/api/*` 请求，用 `localStorage` 完整实现原服务端语义（报告草稿、删除、反馈、分享令牌、双人邀请与共同报告）。
- 分享链接、伴侣邀请链接把报告数据内嵌在 URL 中（`#shared/…`、`#join/…`），因此**跨设备打开依然有效**。
- 双人测评在纯静态模式下采用「链接接力」：发起人完成作答 → 复制邀请链接给伴侣 → 伴侣独立作答后，页面上会出现**回传链接** → 发回给发起人打开，即可在发起人设备上看到双方共同报告。

## 功能

- 四步送礼问卷、约束过滤、可解释推荐、预算与购买前确认项。
- 单人及双人 24 题测评、六维评分、共同有效题目对照、私人备注。
- 报告保存在本浏览器（localStorage），支持草稿、继续填写、删除。
- 分享链接（单人报告）、打印 / 保存 PDF、示例报告、反馈。

## 边界

- 数据仅存于访客自己的浏览器，清除浏览器数据会丢失；不再有服务端账号会话。
- 双人共同报告依赖双方互相传递链接（邀请链接 + 回传链接），无法实时同步进度。
- 推荐和报告使用透明规则，不调用生成式 AI，不提供实时商品价格、库存或购买链接。问卷自编，未经心理测量学验证。
